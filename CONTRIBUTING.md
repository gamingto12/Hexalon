# Contributing to Hexalon

Thanks for your interest in contributing to Hexalon.

## How to contribute

- Open an issue before starting major work so the maintainers can confirm the direction.
- Keep changes focused and easy to review.
- Follow the existing code style and project structure.
- Test your changes locally before submitting a pull request.
- Include a clear description of what changed and why.

## Pull requests

- Create a branch for your work.
- Keep commit messages clear and specific.
- Submit a pull request with a brief summary, testing notes, and any relevant screenshots or logs.
- Be open to feedback and iterate on the review.
