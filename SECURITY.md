# Hexalon Security Reporting

If you happen to come across any security vulnerabilities in the plugin. Please report them through one of these channels:

* Direct email: me@gamingto12.me
* Discord: gamingto12
* My Discord server: https://gamingto12.me/discord

**Do NOT use a public GitHub Issue to report a security vulnerability, as you put the plugin more at risk of people exploiting it.**

For other general bug reports or issues, please open an issue on this GitHub repository, or send it to my Discord server.
